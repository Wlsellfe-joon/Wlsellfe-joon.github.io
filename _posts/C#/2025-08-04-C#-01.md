## Build a Layout, Not a Coordinate Map

컨트롤을 절대 좌표로만 배치하면 창 크기, DPI, 글꼴, 번역된 문구가 바뀔 때 쉽게 겹친다. 먼저 `TableLayoutPanel`, `FlowLayoutPanel`, `Panel`, `SplitContainer` 같은 컨테이너로 큰 구조를 잡는다.

## Dock vs. Anchor

| Property | Use it when | Behavior |
| --- | --- | --- |
| `Dock` | 컨테이너의 한쪽 면이나 전체를 채울 때 | 부모의 지정된 가장자리에 붙고 함께 늘어난다 |
| `Anchor` | 특정 가장자리와의 간격을 유지할 때 | 창 크기가 변해도 선택한 면과의 거리를 유지한다 |

```csharp
mainLayout.Dock = DockStyle.Fill;
saveButton.Anchor = AnchorStyles.Right | AnchorStyles.Bottom;
nameTextBox.Anchor = AnchorStyles.Left | AnchorStyles.Right;
```

<img src="/assets/posts/CS01/CS08.PNG" alt="TableLayoutPanel with grouped controls">

Dock은 Z-order 영향을 받는다. 여러 컨트롤이 같은 면에 dock되어 예상과 다르면 Document Outline에서 순서를 확인한다.

<img src="/assets/posts/CS01/CS10.PNG" alt="Docked Windows Forms layout">

Anchor에서 Left와 Right를 함께 선택하면 가로 폭이, Top과 Bottom을 함께 선택하면 세로 폭이 늘어난다.

<img src="/assets/posts/CS01/CS12-1.PNG" alt="Anchor property configuration">

## MinimumSize, AutoSize, and DPI

창을 너무 작게 줄이면 컨트롤이 겹치거나 잘릴 수 있다.

<img src="/assets/posts/CS01/CS14.PNG" alt="Overlapping controls in an undersized form">

Form의 `MinimumSize`를 설정하고 텍스트 길이가 달라질 Label과 Button에는 `AutoSize`도 검토한다.

```csharp
MinimumSize = new Size(800, 600);
AutoScaleMode = AutoScaleMode.Dpi;
descriptionLabel.AutoSize = true;
```

<img src="/assets/posts/CS01/CS15.PNG" alt="MinimumSize configured on the form">

고해상도 디스플레이를 지원하려면 레이아웃 패널을 사용하고 실제 100%, 125%, 150% 배율에서 확인한다. `AutoScaleMode`는 프로젝트 전체에서 일관되게 사용한다.

## Practical Checklist

1. Form 전체를 채우는 최상위 레이아웃 컨테이너를 둔다.
2. Row/Column의 `SizeType`을 Absolute, AutoSize, Percent 중 목적에 맞게 선택한다.
3. 컨테이너는 `Dock`, 내부 입력 컨트롤은 `Anchor`를 먼저 검토한다.
4. `Margin`과 `Padding`으로 간격을 통일한다.
5. `MinimumSize`와 스크롤 가능 여부를 결정한다.
6. 긴 문구, 다른 DPI, 키보드 Tab 순서에서 테스트한다.
